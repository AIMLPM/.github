# What the badge on this profile means

The badge is generated from GitHub's own records, not typed in. It describes one person, Paul Save, directing a fleet of coding agents to build [iD8](https://github.com/AIMLPM), so the volume is deliberately not what one person typing looks like.

**Contributions per active day, GitHub calendar.** GitHub's contribution calendar for the trailing 365 days, private repositories included via the "include private contributions" setting, divided by the number of days with any activity. The same totals are visible on the public profile.

**Commits per active day → substantive.** The first number is every commit GitHub attributes to this account on the default branches of the 24 repositories it owns, 19 of them private, read from GitHub's copy and deduplicated by SHA. The second removes merge commits, automation-pattern commits (release chores, version bumps, evidence rows written by the pipeline itself) and micro-commits, and is the fairer figure.

**Best day → substantive commits that day.** The raw calendar maximum, and the same day counted in substantive commits.

**Momentum.** The mean of the last 30 active days against a baseline built from earlier 30-active-day windows. Above 2× for two consecutive windows would read "sustained"; today it is one window.

**Why 7,067 commits and 8,301 contributions are different numbers.** The calendar counts four things: commits, pull requests, issues, and reviews, across every repository the account has contributed to. The commit figure counts commits only, on default branches of owned repositories. The commit figure will always be the smaller one, and it is bounded by the calendar total anyone can check.

**Why it is credible.** Nothing here was entered by hand. Anyone granted read access to the repositories can reproduce the commit count, and the calendar total is public. The substantive figure exists precisely because raw commit counts flatter agent-driven work.

Regenerated monthly by the same pipeline that produced the Unlock Radar, a screen over 38 well-known builders' public GitHub activity.
