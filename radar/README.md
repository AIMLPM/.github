# Unlock Radar badge

The badge on this profile is generated from GitHub's own data, not typed in.

- **Daily contributions, private included.** GitHub's contribution calendar for the trailing 365 days, with the "include private contributions" setting on. Anyone can see the same totals on the public profile.
- **Contributions per active day.** Calendar total divided by days with any activity.
- **Commits per active day, and the substantive part.** Commits read from GitHub's copy of every repository this account owns, private ones included, deduplicated by SHA, default branches only. "Substantive" excludes merge commits, automation-pattern commits (release chores, version bumps, evidence rows) and micro-commits. The count is bounded by the public calendar total, which is stated on the badge.
- **Best day, and its substantive count.** The raw calendar maximum and the same day counted in substantive commits.
- **Momentum.** Eight non-overlapping windows of 30 active days. "Sustained" means the last two windows are both about double the baseline; "Emerging" means only the last one is.

Provenance is stated on the badge itself. Regenerated monthly.
