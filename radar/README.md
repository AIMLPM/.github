# What the graph on this profile means

The graph is generated from GitHub's own records, not typed in. This account is read the way [Unlock Radar](https://velocity.id8.one) reads any public GitHub profile, plus one thing only the owner can add: his own repositories, private ones included, read from GitHub's copy with his own access.

**Contributions per active day, GitHub calendar.** GitHub's contribution calendar for the trailing 365 days, private repositories included via the "include private contributions" setting, divided by the number of days with any activity. The same totals are visible on the public profile.

**Commits per active day → substantive.** The first number is every commit GitHub attributes to this account on the default branches of the repositories it owns, private ones included, read from GitHub's copy and deduplicated by commit hash. The second removes merge commits, automation-pattern commits (release chores, version bumps, evidence rows written by the pipeline itself) and micro-commits, and is the fairer figure. Anyone granted read access to the repositories can reproduce both.

**Peak day → substantive commits that day.** The raw calendar maximum, and the same day counted in substantive commits.

**Momentum.** The mean of the last 30 active days against a baseline built from earlier 30-active-day windows.

**Why the commit count and the calendar total differ.** The calendar counts commits, pull requests, issues and reviews across every repository the account has contributed to. The commit figure counts commits only, on default branches of owned repositories, and stays within the calendar total anyone can check.

**Why it is credible.** Nothing here was entered by hand. The calendar totals are public; the commit figures are reproducible by anyone with read access to the repositories.
